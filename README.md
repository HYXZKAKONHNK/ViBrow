# ViBrow
ViBrow — кастомный Python-браузер с собственным DOM, CSS и JS движками. Имеет многовкладвочный интерфейс, локальный кэш, cookies, встроенный поисковик и прокси-мост для обхода блокировок. Был создан 1 разработчиком, без сторонних библиотек. Потребляет в 1 вкладке 75МБ ОЗУ, нужен 700МГц процессор 1 ядро и 200МБ ОЗУ LPDDR1. Работает на чистом Python
